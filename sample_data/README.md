# Sample Data

This directory is for test images used during development and demos.

## Usage

Place a face image (JPG/PNG/WEBP) in this directory and use it with the pipeline.

## Important

- Only use images you are authorized to process.
- Do not commit images of private individuals.
- Use publicly available images for demos (e.g., stock photos, your own photo).
- Images are processed temporarily and not stored permanently.
